## Shop Keeper Game
### Version 1.0 Release
Run a small shop where you sort your delivered items, then when the shop opens, you give the customers what you want, and you make money

### Features
1. Take inventory of delivered items each day, 
2. sort your items
3. open your shop and serve customers

In this small game, a small shop front is generated and some items spawn inside it. 
Customers spawn at the front window. 
Constraints include number of items coming in each day, time limit during service.
Making the most money is the goal of the game.
The challenge is to serve as many customers as possible within the service time, (be more organized makes it quicker to grab the items you need!)

### AI Disclaimer
AI was used heavily in the process of learning python Object-Oriented Programming conventions and syntax in python
and was used to assist me in writing the more complex OOP scripts that I needed to build the foundation of my game

### Script Tags
All scripts in the project have 1 of 4 tags listed below at their header to tell the viewer how involved AI was in programming for that script

Only scripts with the tag `Manual` and `AI Assisted` were used for scoring in the final project slideshow

`Manual` Fully written by me, no AI intervention

`AI Assisted` Script was mostly written by me, some AI intervention to correct errors or fill in function/methods/code blocks

`AI Modified` Script was mostly written by AI, some manual intervention to correct errors or fill in function/methods/code blocks

`AI Generated` Script fully written or almost fully written by AI
